状态：草稿 draft
↓
提交采购申请
  • 厨师 / 店长提交，提交后不可再编辑
状态：已提交 submitted
↓
跟踪供货进度
  • 订单详情按供货商分组展示
  • 待确认 / 已确认 / 已发货（S6）
  • 首页铃铛未读标，消息中心收「供货商已发货」通知
  • 厨师不见供应商名称，仅状态标签
↓
收货验货
  • 店长 / 采购员验收（厨师无资格），支持分批收货
  • 可拍照上传凭证，标记异常行（少货 / 质量 / 逆错）
  • 手动单收货：无价不标异常（S9，预期行为）
部分收货 已收货 收货异常
↓（仅手动单）
🧾 上传付款凭证（S9 新增）
  • 手动商品专用单收货后，店长/采购员上传付款证明或发票
  • 提交后进入「待核销」，等待管理员核销
待提交凭证 待核销 pending
管理员 / 采购员
↘ 审批列表
审核采购单
  • 可调整各商品批准数量
  • 驳回必须填写原因
  • 通知即下单推送告知供货商新订单
  • 手动商品专用单走特殊审批：只审该不该买 / 数量，不核协议价（S9）
已通过 approved 已驳回 rejected
↓ 通过
改量重发（如审核改量 · S2）
  • 报表按批准数量重发，旧版 superseded
  • 清空各供货商确认，打回待确认
  • 提醒经办人线下通知供应商重新确认
异常处理（如有）
  • 异常记录：处理中 → 转写结果
  • 裁决：按实收补款 / 维持不付款
  • 裁决结果同步供货商收货记录页（S7）
  • 处理后可对收货单补结算
处理中 已解决
订单作废（可选 · B8）
  • 审批前：管理员直接作废
  • 审批后：采购员申请取消，管理员确认
  • 已收货不可作废
  • 作废后提醒经办人线下告知供应商
状态：已作废 cancelled
↓（仅手动单）
✅ 凭证核销（S9 新增）
  • 核销通过：按凭证回填实付金额（verify_amount），单据闭环
  • 驳回：填原因，门店重新提交凭证
  • 待核销单留在管理员待办催办，不计入已完成统计
已核销 approved 已驳回 rejected
供货商
↘ 门户消息中心
接收新订单通知
  • 审核通过后立即触达：站内消息 + 门户通知条 + 微信服务通知（待模板号开通）
  • 手动商品专用单不推送、供货商不可见（S9）
↓
查看采购订单
  • 仅见含自家商品的订单与自家明细
  • 草稿 / 已驳回不可见
  • 部分收货不归入已完成（S8）
↓
确认接单
  • 一单多供应商各自确认，互不碍主状态
  • 确认窗口：已提交 / 已通过（S1）
  • 改量后确认被重置，需重新确认（S2）
确认：已确认 confirmed
↓
备货发货
  • 发货窗口：已提交 / 已通过 / 已生成报表 / 部分收货（S1+S8）
  • 发货即向门店/门店店长发消息（关联单号）
  • 收货记录页对照：实收 × 协议价格，可见异常进度与裁决结果（S7）
确认：已发货 shipped
系统（自动）
提交 / 收货成功后自动生成 CSV 报表；失败自动打标待补生成，管理员可补生成（补生成不再清空供货商确认）
① 提交时生成
  • 门店下单报表：手动商品专用单打标「线下采购，凭证核销」（S9）
  • 供应商订货汇总（按供应商分组）
  • 手动商品无归属供货商：不进订货汇总、不推送（S9 拍板维持）
② 审核通过 / 改量时
  • 通过 → 推送消息 + 推送至其供货商
  • 改量 → ② 旧版 superseded，按批准数量重发，并清空供货商确认
③ 收货时生成
  • 门店收货报表（含异常明细）
  • 门店带价格收货报表（仅可付款行）
④ 收货时按供应商生成
  • 供应商到货汇总 / 供应商带价账单（仅可付款行，异常行不进此单）
  • 手动商品行不计价（S9）：金额待凭证核销回填，不进带价报表
⑤ 汇总报表（手动触发）
  • 门店日汇总 · 门店月汇总
⑥ 异常补结算
  • 异常解决后按可付款行生成补充账单
⑦ 手动单凭证核销（S9 新增）
  • 收货后：凭证上传云存储（vouchers/）
  • 核销通过：实付金额回填订单 verify_amount，闭环
  • 价格体系划界：协议价只服务档案商品
状态流转： 草稿 已提交 已通过 待处理 / 部分收货 驳回 / 异常 供货商确认 待核销（手动单 · S9） 已核销（手动单 · S9）
驳回单可复制为新草稿再提 · 已收货订单不可作废 · 改量重发后供货商需重新确认 · 手动商品专用单（S9，9-22 拍板）：强制拆单、特殊审批、收货无价不标异常、凭证核销回填实付金额后闭环
